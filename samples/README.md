# Temsili kod örnekleri

Bu klasördeki dosyalar DryCar Care’de kullandığım yaklaşımı kısa ve okunabilir biçimde göstermek için yeniden düzenlenmiştir.

- Production uygulamasının tam kaynak kodu değildir.
- Veritabanı şeması, endpointler, kimlik bilgileri ve işletmeye özel detaylar içermez.
- C# örnekleri tek proje olarak derlenir; Python örneği standart kütüphaneyle sözdizimi kontrolünden geçer.
- Gerçek sistemde bu politikalar transaction, kalıcı veri, logging, gözlemlenebilirlik ve hata yönetimi katmanlarıyla birlikte çalışır.

Amaç bir kod arşivi sunmak değil; problem çözme biçimini ve güvenlik yaklaşımını göstermektir.
